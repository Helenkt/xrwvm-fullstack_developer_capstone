# Best Cars Dealership Portal

Best Cars Dealership Portal is a Django and React capstone application for a national car dealership network. The application lets visitors browse dealership locations, filter dealers by state, view dealer details and reviews, register an account, log in, and post a review for a selected dealer.

## Project Details

- Backend: Django
- Frontend: React components and static HTML pages
- Data: dealership, review, car make, and car model records
- Key features: authentication, dealer browsing, state filtering, dealer reviews, review sentiment analysis, and admin management for car makes and models
